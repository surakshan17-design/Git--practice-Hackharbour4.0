 PG Complaint Management

A simple complaint management system for apartments and PGs.

 Technologies

* HTML
* CSS
* JavaScript

 Files


PG-Complaint/
├── Day.html
├── Day.js
└── README.md


 Setup

1. Download or clone the project.
2. Open the project folder in VS Code.
3. Open Day.html in a browser.
4. Enter complaint details and click **Submit Complaint**.
5. Use search, filter, status update, and delete options.

 Note

Complaint data is stored temporarily in JavaScript and will be lost after refreshing the page.
